Image Reachability Test

This page loads images directly with plain <img>. If you still see text or red errors, the files are not where the page expects them. Paths are case-sensitive.

If any tile shows ❌ Not found, the corresponding file isn’t present at that exact path. Fixes:

  • In your repo, open assets/ and make sure filenames are exactly tre-01.jpg … tre-10.jpg (lowercase “.jpg”, leading zero).
  • Make sure they’re directly under /assets (not /assets/assets or a nested folder).
  • On GitHub, you can rename files in the UI (three dots → Rename). Change .JPG to .jpg if needed.
  • After rename, hard refresh your site (Ctrl+F5 or Cmd+Shift+R).
